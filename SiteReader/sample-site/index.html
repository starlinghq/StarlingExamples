Alder Point Public Library

The Alder Point Public Library serves the town and the three villages along the estuary. We lend books, films and tools, run a maker space, and host events for every age.

New this autumn: the tool library now lends pressure washers and tile cutters, and the Repair Café moves to Saturday mornings.
